# Changelog

## 1.0.0

First versioned source-available release of DryKraft.

- CRM, sales pipelines, custom objects, CSV imports, saved lists, and dashboards.
- Invoices, purchase orders, expenses, approvals, and reusable templates.
- Campaigns and sequences for email, SMS, voice, and WhatsApp, with email warmup limits.
- Calendar booking, visual workflow automation, execution history, and the transactional outbox.
- Workspace administration, account security, developer APIs, signed webhooks, and reseller tools.
- Local setup documentation, coding-agent instructions, and GitHub forms for bugs and enhancements.

Outbound delivery, calendar sync, and billing require provider configuration.
WhatsApp AI replies require a chat endpoint, model, and private API key.
